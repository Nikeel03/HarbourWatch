One-time setup

This page gets its live ship data from aisstream.io through a small free relay, so the API key never has to sit in this page or in any visitor's browser.

  1. Deploy the companion worker.js file to a free Cloudflare Worker (one-time, a few minutes — see the setup guide).
  2. Copy the .workers.dev address you're given.
  3. Paste it into the RELAY_URL constant near the top of this file's script, then re-upload to GitHub.

Once that's done, this page just works for anyone who opens it — including your aunt — with nothing to paste in.
